<objective>
Ship the server-side emission core: a new `quotesRouter` in `packages/api` exposing two anonymous `publicProcedure`s — `quotes.compute` (resolve + compute, no DB write) and `quotes.create` (compute + persist the versioned snapshot) — plus a tRPC `errorFormatter` that surfaces the engine's machine-readable `QuoteError.code` to the client. Purpose: This is the QUOTE-01/QUOTE-02 crux — an anonymous buyer's quote is computed and persisted server-side through the app pool, keeping the tenant-private tables private (Pitfall 5, the milestone's #1 integration trap).

| anon client (fase 6 UI) → quotesRouter | Untrusted IDs + modalidad cross here; NEVER an orgId, price, or CAC value |

| quotesRouter → withTenant (app pool, NOSUPERUSER/NOBYPASSRLS) | Tenant-scoped CAC/price read + snapshot insert; RLS is the boundary |
