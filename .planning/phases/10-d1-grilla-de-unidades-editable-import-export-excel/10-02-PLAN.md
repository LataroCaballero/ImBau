<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Uploaded .xlsx → parser | Untrusted spreadsheet bytes cross into `parseWorkbook`; cells may be formulas, dates, richText, or errors masquerading as numbers. |
| App-authored strings → exported .xlsx | User-derived identificador/estado could carry formula/CSV-injection payloads that execute when the file is opened. |

| T-10-FLOAT-MONEY | Tampering/Integrity | `parseMoneyEsAr` | high | mitigate | Integer-only parse + `Number.isInteger` gate + fast-check property that no input yields a non-integer (Task 1); ASVS V5 |
| T-10-CSV-INJECT | Tampering | `buildWorkbook` / `sanitizeCell` | high | mitigate | `'`-prefix every string cell starting with `= + - @` tab CR, applied uniformly; adversarial-identificador test (Task 1); ASVS V5/V12 |
