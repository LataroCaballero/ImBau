## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser client → /api/trpc/quotes.* | compute/create cross here; the dedicated batch link keeps them under the nginx rate-limited path |
| URL params (?u/?plan) → client | Untrusted deep-link params drive the selection |
| CTA → wa.me | The browser navigates off-site to a pre-filled WhatsApp URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-05-DOS | Denial of service | compute spam under fast slider drags / burst | high | mitigate | Debounce + discrete presets keep volume under 10r/s+burst20; the dual splitLink (Plan 02) keeps compute on the nginx-throttled path; the UI tolerates 429 (soft retry) |
| T-06-05-RACE | Tampering (integrity of displayed value) | out-of-order compute responses overwrite the current selection | high | mitigate | Monotonic sequence ref drops stale responses in compute onSuccess (Pattern 3) |
| T-06-05-WRITEAMP | Denial of service / data integrity | quotes.create fired on navigation/recompute → snapshot spam | medium | mitigate | create fires ONLY on the CTA (D-06); grep-guarded |
| T-06-05-XSS | Tampering | Reflected `?u`/`?plan` params or wa-preview text | low | mitigate | React auto-escapes; params used only as tRPC uuid inputs (server-validated); no dangerouslySetInnerHTML |
| T-06-05-REDIRECT | Tampering | Open redirect via the WhatsApp link | medium | mitigate | buildWhatsappUrl (Plan 04) fixes the https://wa.me/ host + digits-only number |
| T-06-SC | Tampering | npm installs | high | mitigate | No new packages; RESEARCH Package Legitimacy Audit covers the phase set |
</threat_model>
