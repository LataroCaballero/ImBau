## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| migration owner role → DB | owns/creates tables; must FORCE RLS so it cannot itself bypass policies |
| public web (anon) → DB | grants must be SELECT-only on catalog, INSERT-only on leads/events, none on quotes/cac_index |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-12 | Elevation of Privilege | owner/migration role bypasses RLS | high | mitigate | `FORCE ROW LEVEL SECURITY` on every new tenant table incl. events parent (Pitfall 1); harness role guard asserts rolbypassrls=false |
| T-01-13 | Information Disclosure | over-broad anon GRANT | high | mitigate | explicit per-table grants: SELECT on catalog only, INSERT-only on leads/events, none on quotes/cac_index; absence asserted in 01-06 |
| T-01-14 | Tampering | schema reaching DB via push/manual edit (drift, unversioned) | high | mitigate | migrate-only; `drizzle-kit push` forbidden; single journal; migrate-from-zero gate |
| T-01-15 | Denial of Service | events insert fails for an unprovisioned month | low | mitigate | DEFAULT partition (D-05) routes any out-of-range ts; worker pre-creates next month (01-05) |
</threat_model>
