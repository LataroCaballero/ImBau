## Resolved phase decisions (visible to every plan)

- **FLAG-A** — partitioned `events` PK is `(id, ts)` (not `id` alone). Resolved in plan 01-04 hand SQL.
- **FLAG-B** — `events.ts` is declared for TYPES only and kept OUT of `drizzle.config.ts schema:`; all events DDL + policies hand-written. Resolved in plans 01-03 / 01-04.
- **FLAG-D** — every project-scoped table carries a denormalized `project_id`; anon-published policy is a uniform single-level `EXISTS (... projects.estado='publicado')`. `unit_prices` gets `project_id` too (plan 01-02).
- **Open A3 / `cac_index` anon visibility → DECIDED: tenant-private.** `cac_index` is org-scoped (no `project_id`), gets NO anon policy and NO anon GRANT; the Fase-3 cotizador reads CAC server-side under the tenant context. Least-privilege default; avoids a non-uniform anon policy. The isolation suite asserts anon SELECT on `cac_index` raises 42501. (Plans 01-02, 01-04, 01-06.)
- **Open `lead_estado` value → DECIDED: ASCII `negociacion`** (no accent). UI renders the accented label. Per D-15 / A4.
- **lead↔quote circular FK → DECIDED: broken via hand SQL.** `leads.quote_id` and `quotes.lead_id` are nullable `uuid` columns with NO Drizzle `.references()` (keeps the module graph acyclic); their single-column FKs to the parent PK are added as idempotent `ADD CONSTRAINT` in plan 01-04 hand SQL. Each row's tenancy is still pinned by its own `(project_id, organization_id) -> projects` composite FK.
