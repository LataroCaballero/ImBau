<objective>
Construir la base de transporte de media y el camino de ENTRADA (MEDIA-01) + el resolver de SALIDA (MEDIA-05) de la pipeline. Tres piezas: (1) el paquete compartido `@imbau/storage` (cliente R2 con el opt-out de checksum, helpers de keys deterministas, y el contrato de cola); (2) el resolver puro `resolveMedia` en `@imbau/db`; (3) el router tRPC `media` (createUpload/confirmUpload presignado) más su runtime (R2 + presigner + productor BullMQ) y el helper de convergencia `registerAndEnqueue` que la seed de Fase 3 consumirá.

Decisiones bloqueadas que materializa este plan: **A5** (se construyen AMBOS caminos — el core `registerAndEnqueue` Node y los endpoints presignados tRPC, testeados pero sin UI este milestone), **A6** (servido público vía `R2_PUBLIC_BASE_URL`, sin GET firmado), y el opt-out de checksum de R2 (RESEARCH Pattern 1, la rotura de integración nº1 de R2).

Purpose: Sin esta base, ni el worker (02-02) ni la seed pueden registrar/resolver media; y MEDIA-01 ("vía API/presigned") + MEDIA-05 (resolver consumible por web y panel) quedan sin cubrir.
Output: paquete `@imbau/storage`, preset `r2Env`, `resolveMedia`, router `media` + runtime + `registerAndEnqueue`, y sus tres suites de test.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → API (createUpload/confirmUpload) | El cliente envía projectId/contentType/size; ninguna key de R2 ni org es confiable — el servidor las deriva. |
| API → R2 | Presign de una única key, content-type-bound, expiry corto; HeadObject antes de encolar. |
| API → Postgres (withTenant) | INSERT/SELECT de media como app_authenticated con GUC de la org de sesión (policy media_tenant). |
| API → Redis | Encolado del job con jobId = mediaId (dedup). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | createUpload (key/org provista por cliente) | high | mitigate | originalKey derivado del mediaId server-side; org = ctx.activeOrgId (protectedProcedure); nunca se leen del input. |
| T-02-02 | Tampering/XSS | createUpload (upload de SVG/polyglot) | high | mitigate | Allowlist z.enum image/jpeg|png|webp|avif; SVG rechazado en el boundary tRPC. |
| T-02-03 | Spoofing | presignPut (URL sobre-amplia/larga) | medium | mitigate | Una URL por upload, ligada a key + content-type, expiresIn 3600. |
| T-02-04 | Elevation | INSERT de media | high | mitigate | withTenant(ctx.activeOrgId) → policy media_tenant.withCheck; sin owner/BYPASSRLS. |
| T-02-05 | (integrity) | filas media huérfanas (presign sin confirm) | low | accept | HeadObject antes de encolar; resolveMedia isReady=false para variants vacío; GC de huérfanas fuera de alcance (nota futura). |
| T-02-SC | Tampering | npm installs (@aws-sdk/client-s3, @aws-sdk/s3-request-presigner) | high | mitigate | Pin EXACTO 3.1076.0 (misma versión client+presigner); auditoría de legitimidad en 02-RESEARCH (first-party AWS, SUS=too-new false-positive, Approved). |
</threat_model>
