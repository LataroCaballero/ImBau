<objective>
Author `calcQuote` — the pure, deterministic core that turns a `QuoteInput` into a `QuoteResult` per modalidad — and prove it with a unit table + fast-check property suite. Contado returns the resolved USD price; financiado computes anticipo (half-up), saldo (price − anticipo − Σrefuerzos), N cuotas (last absorbs remainder), each cuota's ARS "al valor del mes" (usd × CAC for `ajuste:'CAC'`, null for fijo), and rejects degenerate plans with typed `QuoteError`s. Every result embeds `ENGINE_VERSION`.

Purpose: ENGINE-01 (contado), ENGINE-02 (financiada with CAC-as-multiplier, never projecting CAC, never inventing FX), and ENGINE-04 (100% coverage + property invariants) — this is the differentiator, "un error de cálculo acá mata el producto" (CLAUDE.md). The founding invariant `anticipo + Σcuotas + Σrefuerzos === precioFinanciado` is asserted EXACTLY.
Output: `engine.ts` (calcQuote), `engine.test.ts` (unit tables + error branches), `engine.property.test.ts` (fast-check invariants).
</objective>
