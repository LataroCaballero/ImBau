<objective>
Lay the back-end foundation for the hotspot editor: (1) resolve the one open schema question by adding `projects.renderExteriorKey` (text, nullable) via a VERSIONED Drizzle migration — the exterior building render's home, the exact peer of `floors.renderKey` / `units.planoKey` (RESEARCH §1); (2) build the pure, I/O-free geometry module (`serialize` / `parse` / `validate`) that is the single source of truth for HSPOT-04's blocking validation (D-08) and the intrinsic-coordinate contract (D-09); and (3) extend the seed idempotently so the draw-over-render happy path is exercisable at UAT (RESEARCH §7).

Purpose: HSPOT-04 requires validated, viewBox-intrinsic polygons consumable as-is by phase 2. The geometry module owns that contract; the migration gives floor polygons a background to be drawn on. Both are prerequisites for the Plan 02 write seam and the Plan 03 editor.
Output: migration `0008`, `projects.renderExteriorKey`, `packages/api/src/hotspots/geometry.ts` (+ unit + property tests, exported as `@imbau/api/geometry`), and a `renders.ts` seed fixture.
</objective>
