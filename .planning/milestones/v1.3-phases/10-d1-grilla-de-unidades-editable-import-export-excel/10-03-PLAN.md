## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Panel client → units router | Authenticated but role-varied requests cross into money mutations; a viewer must be denied server-side, not by UI hiding. |
| Active org → other org rows | RLS + composite FKs must make cross-tenant unit/price writes structurally impossible; a cross-org id must be indistinguishable (NOT_FOUND). |
| Uploaded base64 .xlsx → importExcel | Untrusted, possibly oversized/malformed spreadsheet bytes enter a transactional write path. |
| Panel write → public web read | A committed write must reflect on the anon (force-dynamic) public surface (GRID-07). |
