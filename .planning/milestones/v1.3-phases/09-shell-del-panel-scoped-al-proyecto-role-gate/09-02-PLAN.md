## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → panel RSC | `params.id` from the URL is untrusted; validated with `z.uuid()` before any query. |
| panel RSC → tRPC caller | Session cookie in headers; `createCaller({ headers })` derives the active org server-side. |
| tRPC caller → Postgres | Reads route through `withTenant` (Plan 01) as `app_authenticated`; RLS is the tenant barrier. |
| RSC role prop → write affordance | `canWrite` from `org.activeMemberRole` gates rendering; it is cosmetic, not the authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-02 | Information Disclosure / EoP | Deep-link to a cross-org project id (BOLA/IDOR) | high | mitigate | Layout/pages resolve via `getForOrg` under RLS; null → `notFound()`. The client id is never trusted; RLS makes the row invisible. |
| T-09-03 | Information Disclosure | Enumeration via 403-vs-404 at the shell | medium | mitigate | Cross-org and non-existent both render `notFound()` (identical 404 + es-AR boundary) — D-07. |
| T-09-05 | Denial of Service | Malformed `params.id` → Postgres 22P02 → 500 | medium | mitigate | `z.uuid().safeParse(id)` in the layout and every tab page before resolution → `notFound()`. |
| T-09-01 | Elevation of Privilege | Viewer reaching a write action in the UI | high | mitigate | Write affordance rendered only when `canWrite` (owner/developer); the server `requireRole` (Plan 01) rejects any forged write regardless — UI gating is defense-in-depth (D-08). No functional write UI ships this phase. |
| T-09-08 | Information Disclosure | RSC error masquerading DB failure as a login bounce | low | mitigate | Narrow catch: only `UNAUTHORIZED`/`FORBIDDEN` → `redirect("/login")`; all other errors re-thrown to the Next error boundary (cloned from `(dashboard)/page.tsx`). |
| T-09-SC | Tampering | npm/pip/cargo installs | low | accept | No net-new packages installed this phase (RESEARCH Package Legitimacy Audit: N/A). |
