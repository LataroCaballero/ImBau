## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tRPC caller → tRPC procedure | The `id` and `estado` inputs are untrusted; validated with `z.uuid()` / `z.enum` at the boundary. |
| tRPC procedure → Postgres | Runs as `app_authenticated` (NOSUPERUSER/NOBYPASSRLS) inside `withTenant`; the `projects_tenant` RLS policy is the tenant barrier. |
| caller role → write authority | `member.role` for the active org is the authorization signal; `requireRole` is the enforcement point. |
| canary write → anon web surface | `estado` toggle changes what `projects_anon_published` exposes via `listPublished` (intentional cross-surface effect). |
